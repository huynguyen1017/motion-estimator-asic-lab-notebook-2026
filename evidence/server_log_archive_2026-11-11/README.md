# ENGR 852 University Server Log Preservation (November 11, 2026)

This directory contains **privacy-redacted text logs and reports** copied from an authorized university server to preserve the original motion-estimator ASIC development history.

The files are **not newly executed tests** and must never be described as such. They include passing results, failing intermediate runs, constraint/library errors, hold/setup violations, and later closure attempts.

## Integrity and provenance
- The original unmodified files remain in a separate **private iMac backup**.
- MANIFEST.json lists each source-relative path, original SHA-256, published SHA-256 and size.
- Personal identifiers, home-directory usernames, hostnames and IP addresses were redacted.
- No licensed PDK rules, FSDB/GDS databases, compiled Synopsys artifacts, private keys, or raw desktop screenshots are included.

## Usage for milestone decks
- Match each file to its actual date and revision before citing it.
- A tool exit code of 0 does not itself prove timing closure.
- Intermediate V5 PrimeTime logs include successfully repaired library errors **and remaining violations**.
- Do not present November 5 results as evidence from the October 1/15/26 milestone deadlines.

See the original repository's RTL, verification and final V9 sign-off evidence for additional context.
